# 奥比岛天空之塔与日常脚本

两个独立的 Windows 免安装工具：天空之塔自动挑战，以及王之试炼中魔·星月、魔·独角兽的日常挑战。

本项目不是游戏官方工具。脚本依赖固定游戏布局与画面识别，不能保证所有电脑、阵容或游戏版本均可运行。首次运行请全程观察，并自行确认游戏对自动化工具的使用规定。

## 下载与启动

发布后请在仓库的 **Releases** 页面下载对应压缩包，不要把 GitHub 的 “Download ZIP” 当作免安装程序。

| 压缩包 | 用途 |
| --- | --- |
| `tower_bot_portable.zip` | 天空之塔，启动时输入本次完成 1～3 轮 |
| `game_daily_bot_portable.zip` | 魔·星月与魔·独角兽日常挑战 |

1. 将整个压缩包解压到一个独立文件夹。
2. 保留程序、启动文件和 `_internal` 文件夹的原有相对位置，不要单独移动 exe。
3. 手动登录游戏，进入下文对应的起始画面。
4. 双击 `run.bat`，根据窗口提示操作。
5. 保持游戏可见，不要同时运行两个脚本，不要操作鼠标键盘或遮挡游戏。

免安装包包含运行环境，无需另外安装 Python。

## 运行环境

- Windows 10 或 Windows 11。
- 屏幕分辨率为 **1920×1080**。
- Windows 设置 → 系统 → 显示 → 缩放，设为 **125%**。
- 浏览器页面缩放设为 **100%**。
- 游戏区域的大小、位置必须与脚本适配布局一致。
- Windows 的“显示缩放”和浏览器的“页面缩放”是两项不同设置，请分别设为上述数值。即使分辨率相同，显示缩放改变后也可能导致识别失败或点击错位，不要通过随意增加页面缩放来补偿。
- 运行期间不要改变浏览器大小、页面缩放或显示设置，不要锁屏、最小化游戏或让电脑休眠。
- 天空之塔层数识别使用 Windows 英语 OCR；出现 OCR 相关错误时，检查英语语言及 OCR 组件是否可用。

## 随时停止

按 **Esc**，或将鼠标快速移到屏幕左上角。

发现点错位置、进入不符合预期的页面或重复点击时，立即停止。先恢复游戏界面，再选择合适的接续入口，不要反复启动消耗游戏次数。

## 天空之塔

### 启动前准备

普通启动支持从“圣精灵之境”主界面或天空之塔外部场景开始。双击 `run.bat` 或 `tower_bot.exe`，输入 **1、2 或 3** 并回车，随后在 5 秒内切回游戏。

请提前按以下用途设置好三个预设队伍。脚本会切换预设队伍，但不会替你搭配成员：

| 预设队伍 | 用途 | 挑战楼层 |
| --- | --- | --- |
| 队伍一 | 速刷队伍（无奶，即不带治疗） 全上输出即可| 第 28 层 |
| 队伍二 | 赖着不死队，以生存和续航为主，建议前排双盾，刚需宙斯 | 第 26 层 |
| 队伍三 | 常规队伍 ，可参考示例：前排玄武、潘多拉，后排月神、爱神、日神| 第 1～25 层、第 27 层 |

以上是队伍定位，不是完整阵容清单；请自行确认队伍强度足以通过对应楼层，强度较低会有中途爬塔失败的风险。

**注意资源消耗：第 27 层会自动购买 15 层魔法防御加成（否则很难打过）每日三次运行完成后能保证经验卡，金贝贝均能够兑换完毕，12张紫卡会差一点，具体完善请等待之后的版本。运行前请确认接受这项游戏内资源消耗。**

### 每轮流程

1. 使用队伍三挑战第 1～25 层。
2. 到第 26 层后退出保存，返回换队伍二，再进塔挑战第 26 层。
3. 第 26 层胜利后退出保存，换队伍三，重新进塔到第 27 层。
4. 第 27 层使用队伍三，选择增强魔防，右三角点击 14 次，确认数量为 15 后，购买 **15 层魔法防御加成**。
5. 确认阵型、调整三倍速、按流程点击 GO，并处理胜利与提示弹窗。
6. 第 27 层胜利后退出保存，换队伍一，再挑战第 28 层。
7. 第 28 层胜利后退出、直接结算并关闭提示；确认回到塔外后，计为完成一轮。
8. 若还有下一轮，先在塔外等待 **10 分钟**，再换队伍三，从第 1 层开始下一轮。最后一轮结束后不等待。

等待期间不会主动移动鼠标或点击，每分钟显示剩余时间，紧急停止仍然有效。若剩余进入次数不足，脚本可能超时停止，不会把未完成的一轮记为成功。

### 中断后接续

接续入口也会询问本次还要完成几轮，当前尚未完成的一轮算在输入数量内。

| 启动文件 | 必须满足的游戏状态 |
| --- | --- |
| `run_from_floor.bat` | 已在塔内未挑战的楼层，当前是队伍三；若在 27 层，本轮魔防加成应尚未购买 |
| `run_from_floor_team2.bat` | 在塔内尚未挑战的 26 层，已选好队伍二 |
| `run_from_floor28.bat` | 在塔内尚未挑战的 28 层，已选好队伍一 |
| `run_resume_switch.bat` | 已保存尚未挑战的 26 层进度，停在塔外，准备换队伍二 |

例如，从 28 层接续时输入 1，只会打完当前 28 层并结算；输入 2 或 3，还会继续后续整轮。

这些入口不适用于战斗中、刚购买加成后或楼层胜利弹窗尚未处理的状态。`progress.json` 仅作记录，不会自动推断中断画面。

### 结束与故障记录

正常完成指定轮数后，程序窗口自动关闭，浏览器保持打开；发生错误会保留窗口和日志。

反馈问题时保留 `run.log`、`error.png`；层数识别问题另附 `floor_ocr.png`，菜单问题另附 `menu.png`。

原包记录已完成截图核对、1～3 轮离线流程及异常分支测试，但未完成实际游戏连续 1～3 轮验证。请不要将离线测试视为通关保证。

## 日常挑战

### 启动方法

1. 先手动切换至**速刷队伍**。
2. 进入**春之露**场景。
3. 关闭遮挡页面的弹窗，确保“王之试炼”图标完整可见、没有被遮挡。
4. 双击日常脚本文件夹中的 `run.bat`，启动脚本即可。

运行期间请保持游戏窗口可见，不要移动窗口或更改缩放。需要停止时，按 `Esc`，或将鼠标移至屏幕左上角。

### 选择入口

| 启动文件 | 起始位置 |
| --- | --- |
| `run.bat` | 包含“王之试炼”入口的游戏主界面 |
| `run_from_challenge.bat` | 魔·星月的左右护法选择页面 |
| `run_from_unicorn.bat` | 魔·独角兽的左右挑战页面 |

### 自动执行内容

1. 从王之试炼进入魔·星月，先挑战左护法。
2. 处理确认阵型、战斗速度和 GO；等待本次 GO 消失后再识别下一次。
3. 战斗胜利后处理胜利确认与返回页面后的奖励确认。
4. 左侧出现次数耗尽提示后，切换右护法；两侧均耗尽后离开魔·星月。
5. 进入魔·独角兽，按同样方式刷完“小魔仙”和“小睡魔”。
6. 确认两侧次数均耗尽后关闭页面并结束。

日常脚本不是天空之塔的 1～3 轮模式，其目标是完成上述挑战的剩余次数。

原包提供剩余次数参数，例如已经停在魔·星月挑战页面时：

```bat
game_daily_bot.exe --start-at-challenge --left-count 9 --right-count 10
```

此例表示指定左、右剩余次数；只在确认当前界面与实际次数相符时使用，不要原样照抄到其他场景。

### 故障记录

日常运行日志为 `运行记录.log`。遇到识别失败时，保留日志和当时的游戏截图。

## 常见问题

### 点击没有反应或点偏了

先停止脚本。检查分辨率、Windows 显示缩放、浏览器页面缩放和游戏区域位置，再确认是否使用了正确的启动入口。不要让脚本在错误画面持续点击。

### 程序文件很大

免安装包包含 Python 运行环境和图像识别等依赖，并非所有体积都是脚本本身。请完整解压，不要删除 `_internal`。

### 被安全软件拦截

不要直接关闭系统防护。先核对下载来源和发布文件，进行安全扫描；无法确认时不要运行。
